# Квиз-калькулятор стоимости

Готовый сайт-калькулятор: клиент отвечает на 6 вопросов с картинками, видит примерную цену, оставляет телефон — и заявка со всеми ответами сразу приходит вам в Telegram.

- Цены, тексты, вопросы и картинки вы меняете **в Google Таблице**, без программиста.
- Хостинг, отправка заявок и e-mail работают **на бесплатных тарифах**.
- Шаблон не привязан к потолкам: готовые настройки для окон, кухонь и кондиционеров лежат в папке `examples/`.

---

## Что лежит в папке

| Файл | Что это |
|---|---|
| `index.html` | Страница сайта |
| `styles.css` | Внешний вид |
| `app.js` | Логика квиза, расчёт цены, отправка заявок. Трогать не нужно |
| `config.json` | Запасные настройки: тексты, цены, вопросы. Работают, если Google Таблица не подключена или недоступна |
| `config.js` | Копия `config.json` — нужна только чтобы открыть сайт двойным кликом на компьютере |
| `sheets/` | 4 файла CSV — заготовка Google Таблицы |
| `worker/worker.js` | Код «пересыльщика» заявок в Telegram для Cloudflare |
| `policy.html` | Политика обработки персональных данных и текст согласия (шаблон) |
| `img/` | Картинки-заглушки. Замените на фото своих работ |
| `examples/` | Готовые ниши: окна, кухни, кондиционеры. В каждой папке `config.json` и `sheets/` для Google Таблицы |

**Посмотреть сайт прямо сейчас:** откройте `index.html` двойным кликом — он заработает в браузере без интернета (заявки, конечно, отправляться не будут).

## Шаг 1. Google Таблица: цены и тексты

### 1.1. Создаём таблицу из заготовки

1. Откройте [Google Таблицы](https://sheets.google.com) → **Пустой файл**. Назовите, например, «Квиз — настройки».
2. **Файл → Импортировать → Загрузка** → выберите `sheets/1-nastrojki.csv`.
   - Место импорта: **Заменить текущий лист**.
   - Тип разделителя: **Запятая**.
   - **Снимите галочку «Преобразовывать текст в числа, даты и формулы»** — иначе телефон `+7 (999)…` превратится в ошибку.
3. Переименуйте лист (двойной клик по вкладке внизу) в **Настройки**.
4. Повторите для остальных файлов, но выбирайте **Вставить новый лист**:
   - `2-voprosy.csv` → лист **Вопросы**
   - `3-varianty.csv` → лист **Варианты**
   - `4-otzyvy-i-raboty.csv` → лист **Отзывы и работы** (необязательный)

### 1.2. Публикуем таблицу

1. **Файл → Поделиться → Опубликовать в интернете**.
2. В первом списке выберите лист **Настройки**, во втором — **Файл CSV (.csv)** → **Опубликовать** → скопируйте ссылку.
3. Повторите для листов **Вопросы**, **Варианты**, **Отзывы и работы**. Получится 4 ссылки вида
   `https://docs.google.com/spreadsheets/d/e/2PACX-…/pub?gid=123&single=true&output=csv`.
4. Откройте `config.json` (на GitHub — значок карандаша) и вставьте ссылки в начало файла:

```json
"sheets": {
  "settings":  "ссылка на лист Настройки",
  "questions": "ссылка на лист Вопросы",
  "options":   "ссылка на лист Варианты",
  "reviews":   "ссылка на лист Отзывы и работы"
},
```

Готово: теперь сайт берёт данные из таблицы. Изменения появляются на сайте **через 1–5 минут** (Google обновляет опубликованную версию не мгновенно). Если таблица вдруг недоступна, сайт покажет последнюю удачно загруженную версию, а если её нет — данные из `config.json`.

> Если будете открывать сайт двойным кликом с компьютера и хотите видеть данные из таблицы, вставьте те же ссылки и в `config.js`.

### 1.3. Лист «Настройки»

Три столбца: **ключ** (не меняйте), **значение** (меняйте), **пояснение** (подсказка). Самое важное:

| Ключ | Что значит |
|---|---|
| `company_name`, `phone`, `city`, `work_hours` | Название, телефон, город, часы работы |
| `whatsapp` | Номер цифрами: `79991234567`. Пусто — кнопки WhatsApp не будет |
| `telegram` | Ник без @ или ссылка `t.me/…` |
| `logo_url` | Ссылка на логотип. Пусто — будет первая буква названия |
| `primary_color` | Цвет бренда, например `#3A5BD9`. Все оттенки сайт подберёт сам. Подобрать цвет: [htmlcolorcodes.com](https://htmlcolorcodes.com/) |
| `hero_title`, `hero_subtitle` | Заголовок и подзаголовок первого экрана |
| `benefit_1` … `benefit_3` | Преимущества в формате `Гарантия 15 лет\|на полотно и монтаж` |
| `gift_text` | Подарок. Пусто — блок подарка исчезнет |
| `gift_discount_percent` | Если подарок — скидка: напишите `10`, и скидка будет «копиться» по мере ответов |
| `min_order` | Минимальная сумма заказа. Итог не будет ниже |
| `price_spread_percent` | Разброс «от … до …»: `15` = ±15% |
| `price_display` | Как показывать цену до ввода телефона: `полностью`, `частично` («от 2X XXX ₽») или `скрыто` |
| `multiplier_applies_to` | `площадь` — множители влияют только на цену полотна; `всё` — на всю сумму (для окон/кухонь) |
| `worker_url` | Адрес воркера для заявок в Telegram (шаг 2–3) |
| `email_mode`, `web3forms_key` | Заявки на почту (шаг 4) |
| `yandex_metrika_id` | Номер счётчика Метрики (шаг 7) |
| `legal_name`, `inn`, `ogrn`, `legal_address`, `email` | Реквизиты — подставятся в политику конфиденциальности |

Остальные ключи подписаны прямо в таблице.

### 1.4. Лист «Вопросы»

| Столбец | Что писать |
|---|---|
| **шаг** | Номер шага: 1, 2, 3… По нему вопросы связаны с вариантами. Порядок на сайте — по этому номеру |
| **вопрос** | Текст вопроса |
| **тип** | `один вариант` · `несколько вариантов` · `ползунок` · `ввод числа` |
| **обязательный** | `да` / `нет` |
| **подсказка** | Серый текст под вопросом (можно пусто) |
| **мин, макс, шаг ползунка, по умолчанию, единица** | Только для ползунка и ввода числа. Например `5`, `200`, `1`, `20`, `м²` |
| **роль** | `площадь` — это число участвует в расчёте (площадь, погонные метры кухни и т.п.). `срочность` — ответ попадёт в заявку отдельной строкой |

Чтобы **добавить вопрос** — добавьте строку с новым номером шага и варианты для него на листе «Варианты». Чтобы **убрать** — удалите строку вопроса.

### 1.5. Лист «Варианты» — здесь все цены

| Столбец | Что писать |
|---|---|
| **шаг** | Номер вопроса, к которому относится вариант |
| **вариант** | Текст на карточке |
| **картинка** | Ссылка на фото (можно пусто). Подходит ссылка «Поделиться» из Google Диска (доступ «Все, у кого есть ссылка») — сайт сам превратит её в картинку |
| **тип цены** | см. ниже |
| **значение** | Число. Можно с запятой: `1,25` |
| **описание** | Мелкий текст под вариантом |
| **единица, кол-во по умолчанию, макс кол-во** | Только для «за штуку»: `шт` / `м`, сколько стоит изначально, максимум |

**Типы цены:**

- `за м2` — цена за квадратный метр (полотно, демонтаж). Если выбрано несколько таких вариантов — цены складываются.
- `множитель` — умножает цену: `1,25` = +25%, `0,9` = −10%.
- `фикс` — фиксированная надбавка в рублях.
- `за штуку` — цена × количество (светильники, метры световой линии). Клиент сам укажет количество кнопками «− / +».
- `нет` — на цену не влияет (например «Когда планируете монтаж»).

**Формула:** `площадь × (сумма цен «за м²») × множители + фиксированные надбавки + количество × цена за штуку`, но не меньше `min_order`. Клиенту показывается диапазон ±`price_spread_percent`.

*Пример:* 40 м², глянец 690 ₽ + демонтаж 150 ₽, парящий потолок ×1,25, 2 помещения +1 500 ₽, 7 светильников по 450 ₽:
40 × 840 × 1,25 + 1 500 + 3 150 = **46 650 ₽** → на сайте «от 39 600 до 53 700 ₽».

### 1.6. Лист «Отзывы и работы» (необязательный)

Столбцы: **фото**, **подпись**, **имя**, **отзыв**. Любой столбец может быть пустым. Лист пустой — блок на сайте не показывается.

### 1.7. Где взять ссылки на картинки

- Проще всего — положить фото в папку `img/` на GitHub (кнопка **Add file → Upload files**) и написать в таблице `img/имя-файла.jpg`.
- Или Google Диск: правый клик по файлу → **Открыть доступ** → «Все, у кого есть ссылка» → скопировать ссылку.
- Размер фото — до 300 КБ (сжать можно на [squoosh.app](https://squoosh.app)), иначе сайт будет медленно открываться на телефоне.

## Шаг 2. Telegram-бот: куда будут приходить заявки

1. В Telegram найдите **@BotFather** → отправьте `/newbot`.
2. Придумайте имя (например «Заявки ПотолокПро») и адрес бота, оканчивающийся на `bot` (например `potolokpro_leads_bot`).
3. BotFather пришлёт **токен** вида `7123456789:AAH…`. Это пароль от бота — **никому не показывайте и не вставляйте на сайт**.
4. Узнаём **chat_id** — номер чата, куда бот будет писать:
   - **Себе в личку:** откройте своего бота и нажмите **Start**. Потом напишите боту **@userinfobot** — он ответит вашим Id (например `123456789`).
   - **В группу** (чтобы заявки видели несколько человек): создайте группу, добавьте туда своего бота. Напишите в группе любое сообщение. Откройте в браузере `https://api.telegram.org/botВАШ_ТОКЕН/getUpdates` и найдите `"chat":{"id":-100…` — это число со знаком минус и есть chat_id группы.
5. Можно указать несколько чатов через запятую: `123456789,-1001234567890`.

## Шаг 3. Cloudflare Worker: пересылка заявок в Telegram

Это маленькая бесплатная программа в интернете. Сайт отправляет заявку ей, а она — в Telegram. Так токен бота никто не увидит.

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/sign-up) (бесплатно, карта не нужна).
2. Слева **Compute (Workers) → Workers & Pages → Create → Create Worker** (кнопка может называться «Start with Hello World!»).
3. Название: `quiz-leads` → **Deploy**.
4. Нажмите **Edit code**. Удалите весь код в окне, вставьте содержимое файла `worker/worker.js` → **Deploy**.
5. Вернитесь в воркер → **Settings → Variables and Secrets → Add**:
   - `TELEGRAM_BOT_TOKEN` — тип **Secret**, значение — токен из шага 2;
   - `TELEGRAM_CHAT_ID` — тип Text, ваш chat_id;
   - `ALLOWED_ORIGINS` — тип Text, адрес вашего сайта, например `https://ivan.github.io` (без слеша в конце; несколько — через запятую). Заполните после шага 5, а пока можно оставить пустым.
   - Нажмите **Deploy** / **Save**.
6. Скопируйте адрес воркера (вверху, вида `https://quiz-leads.ваш-ник.workers.dev`). Откройте его в браузере — должно быть `"telegram":"настроен"`.
7. Вставьте этот адрес в таблицу, ключ **`worker_url`**.
8. Пройдите квиз на сайте и отправьте тестовую заявку — она придёт в Telegram.

Защита от спама уже встроена: скрытое поле-ловушка для ботов, не больше одной заявки в минуту с одного устройства и не больше 5 заявок за 10 минут с одного IP-адреса.

## Шаг 4. Резервная отправка на e-mail (по желанию)

Если Telegram вдруг недоступен, заявка уйдёт на почту.

1. Зайдите на [web3forms.com](https://web3forms.com), введите свою почту → получите **Access Key** в письме.
2. В таблице: `web3forms_key` — этот ключ, `email_mode` — `резерв` (почта только если Telegram не сработал) или `всегда` (дублировать каждую заявку).

Если не сработало вообще ничего, клиент увидит кнопки «Написать в WhatsApp / Telegram» с уже готовым текстом заявки и кнопку «Скопировать» — заявка не потеряется.

## Шаг 5. Публикация сайта (бесплатно)

### Вариант А: GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com).
2. **New repository** → имя, например `potolki` → **Public** → **Create**.
3. **uploading an existing file** → перетащите все файлы и папки проекта → **Commit changes**.
4. **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main**, папка **/(root)** → **Save**.
5. Через 1–2 минуты сайт будет по адресу `https://ваш-ник.github.io/potolki/`.

### Вариант Б: Netlify (ещё проще)

1. Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop).
2. Перетащите **папку проекта** целиком в окно браузера.
3. Через несколько секунд получите адрес вида `https://случайное-имя.netlify.app` (поменять: **Site configuration → Change site name**).

После публикации:
- впишите адрес сайта в `ALLOWED_ORIGINS` воркера (шаг 3.5);
- в `index.html` замените строку `og:image` на полный адрес картинки (`https://ваш-сайт/img/og-image.png`), а также `og:title` и `og:description` — это превью ссылки в мессенджерах. Мессенджеры не читают таблицу, поэтому эти 3 строки правятся в файле вручную.

## Шаг 6. Свой домен (по желанию)

1. Купите домен (например, на reg.ru или nic.ru), ~200–900 ₽ в год за `.ru`.
2. **GitHub Pages:** Settings → Pages → Custom domain → впишите `potolki.ru` → Save. У регистратора домена добавьте DNS-записи: четыре записи **A** на `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` и запись **CNAME** `www` → `ваш-ник.github.io`. Через несколько часов включите галочку **Enforce HTTPS**.
3. **Netlify:** Domain management → Add a domain → следуйте подсказкам (Netlify покажет, какие записи добавить у регистратора).
4. Не забудьте добавить новый адрес в `ALLOWED_ORIGINS` воркера.

## Шаг 7. Яндекс Метрика (по желанию)

1. [metrika.yandex.ru](https://metrika.yandex.ru) → **Добавить счётчик** → адрес сайта → получите номер (только цифры).
2. Впишите его в таблицу: `yandex_metrika_id`.
3. В Метрике **Цели → Добавить цель → JavaScript-событие** и создайте цели с идентификаторами:
   - `quiz_start` — начал квиз;
   - `quiz_step_2`, `quiz_step_3`, … — дошёл до шага N;
   - `quiz_form` — дошёл до формы;
   - `lead_sent` — отправил заявку;
   - `lead_failed` — заявка не ушла автоматически (клиенту показаны кнопки мессенджеров).

Вебвизор специально выключен: он может записывать номер телефона.

## Шаг 8. Политика конфиденциальности

Заполните в таблице `legal_name`, `inn`, `ogrn`, `legal_address`, `email` — реквизиты появятся в `policy.html` сами. Места, которые нужно дописать вручную, подсвечены жёлтым (дата, срок хранения, хостинг).

Важно: это шаблон, а не юридическая консультация. По закону 152-ФЗ оператор персональных данных должен подать уведомление в Роскомнадзор; кроме того, Telegram и Cloudflare — зарубежные сервисы (трансграничная передача данных). Покажите текст юристу перед запуском.

## Другие ниши: окна, кухни, кондиционеры и любые услуги

Сам сайт (`app.js`) ничего не знает про потолки. Вопросы, варианты, цены, тексты и цвет — это данные, поэтому новая ниша делается **заменой настроек, без правки кода**.

### Готовые ниши

| Папка | Ниша | Как считается цена |
|---|---|---|
| корень (`config.json`) | Натяжные потолки | площадь × цена полотна за м² × множители + опции |
| `examples/okna` | Пластиковые окна | окна по типам × количество, профиль и стеклопакет — множители на всю сумму |
| `examples/kuhni` | Кухни на заказ | длина кухни (пог. м) × (фасады + столешница) × планировка + техника и опции |
| `examples/kondicionery` | Кондиционеры | кондиционеры по мощности × количество × тип × класс бренда + трасса, помпа, демонтаж |

В каждой папке есть `config.json` и `sheets/` — 4 CSV-файла для Google Таблицы.

**Как запустить готовую нишу:**
- *с Google Таблицей* — импортируйте CSV из `examples/<ниша>/sheets/` по шагу 1 (вместо файлов из корневой папки `sheets/`);
- *без таблицы* — скопируйте `examples/<ниша>/config.json` в корень сайта вместо `config.json` (и его содержимое в `config.js` после `window.QUIZ_CONFIG =`, если открываете сайт двойным кликом).

Затем поменяйте в «Настройках» название, телефон, мессенджеры, цвет и цены — и всё.

### Как собрать новую нишу за 15 минут

1. Возьмите за основу самую похожую готовую нишу:
   - цена зависит от **площади или длины** (потолки, кухни, ремонт, полы, плитка, заборы) → потолки или кухни;
   - цена зависит от **количества штук** (окна, кондиционеры, двери, светильники, установка камер) → окна или кондиционеры.
2. Решите, что будет «базой» цены:
   - **площадь / длина** → вопрос-ползунок с ролью `площадь` и варианты с типом `за м2` (на самом деле это «за единицу базы»: за м², за погонный метр, за сотку);
   - **штуки** → вопрос «несколько вариантов» с типом `за штуку` — у каждого варианта появятся кнопки «− / +».
3. То, что делает всё **дороже или дешевле в разы** (класс материала, бренд, сложность, этажность), — тип `множитель`. Если множители должны влиять на всю сумму, а не только на площадь, поставьте `multiplier_applies_to` = `всё`.
4. Разовые доплаты (демонтаж, выезд за город, срочность) — `фикс`. Вопросы для информации (этаж, сроки) — тип цены `нет`.
5. Последний вопрос «Когда планируете?» пометьте ролью `срочность` — он придёт в Telegram отдельной строкой.

Ещё идеи:
- **Ремонт квартир:** ползунок «Площадь квартиры» (`площадь`); тип ремонта (косметический / капитальный / дизайнерский) — `за м2`; новостройка или вторичка — `множитель`; электрика, сантехника — `за м2` или `фикс`.
- **Заборы:** ползунок «Длина забора, м» (`площадь`); материал (профлист, евроштакетник, кирпич) — `за м2`; высота — `множитель`; ворота и калитки — `за штуку`.
- **Двери:** межкомнатные и входные — `за штуку` с количеством; покрытие — `множитель`; демонтаж — `за штуку`.

### Несколько ниш на одном сайте

Каждой странице можно дать свой файл настроек. Скопируйте `index.html`, например, в `kuhni.html` и в строке `<body …>` допишите адрес файла:

```html
<body id="top" data-page="quiz" data-config="examples/kuhni/config.json">
```

Теперь `сайт/kuhni.html` — лендинг кухонь, а `сайт/` — потолков. Прогресс клиентов и кеш у страниц хранятся раздельно. Подключить свою Google Таблицу к такой странице можно в разделе `sheets` её файла настроек. Двойной клик по такой странице на компьютере не сработает: её нужно открывать с сайта.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Изменения из таблицы не видны | Подождите 5 минут и обновите страницу. Проверьте, что листы опубликованы именно как **CSV** и ссылки вставлены в `config.json` |
| Вместо данных из таблицы показаны старые | Если таблица не открывается, сайт показывает последнюю удачную версию. Откройте ссылку на CSV в браузере — должна скачиваться таблица, а не страница входа |
| Заявки не приходят | Откройте адрес воркера в браузере: должно быть `"telegram":"настроен"`. Проверьте `ALLOWED_ORIGINS` — адрес сайта должен совпадать точно (с `https://`, без `/` в конце). Нажмите боту **Start** |
| Телефон в таблице показывает ошибку | Ячейка начинается с `+` и таблица считает её формулой. Поставьте перед номером апостроф: `'+7 (999) 123-45-67` |
| Вопрос не появился | У вопросов с вариантами должна быть хотя бы одна строка на листе «Варианты» с тем же номером шага |

Для проверки откройте на сайте консоль браузера (F12 → Console): там написано, откуда загружены настройки (`Google Таблица`, `кеш` или `config.json`), и предупреждения о пропущенных вопросах.
